## Complementos editoriales añadidos

Se añadieron el puente con los módulos 2–3, la separación de numeraciones, tablas de lectura, contraejemplos, organización por acontecimientos, ejemplo de dos escalas y seis ejercicios con soluciones. No se atribuyen al profesor los datos ficticios 100–108, 120–100, 120–112,36 ni 90–87.

Los cálculos del laboratorio se verifican por separado: 20 % y 60 % para las recuperaciones; 116,18 para el retroceso medio; amplitud 20 y proyecciones 107,64, 104,72 y 100. No son backtesting ni objetivos de una operación real.

No se añadieron fuentes externas, videos, imágenes nuevas, reglas automáticas ni contenido de módulos posteriores. Para la futura integración visual, las referencias de cada bloque quedan identificadas; las imágenes que entregue el usuario se archivarán y revisarán antes de usarlas.
